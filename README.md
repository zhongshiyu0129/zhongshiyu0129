### SIGNAL / 关于我

我对智能、科学与创造的交汇处保持好奇。喜欢拆解复杂问题，也喜欢让一个尚未成形的念头，长成真正可用的工具。

从科研协作到内容创作，我正在探索 AI 如何进入真实工作流：让知识更容易被理解，让想法更快得到验证，让人有更多空间去判断和创造。

> **Seek truth. Build beyond.**  
> 在已知中求证，在未知中构建。
